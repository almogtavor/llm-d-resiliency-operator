Adding an example​

An example is a JSON file in docs/scenarios, shown on any page by one line:

[example my-scenario]: ../scenarios/my-scenario.json

GitHub hides that line; the site replaces it with the stepper, and with it any figure right above it. The file lists the Pods once, then the steps; each step names only what changed.

{
  "title": "m0 dies",
  "page": "failures/my-page",
  "pods": [{"name": "pod-0", "uid": "a1", "members": {"m0": "serving"}}],
  "steps": [
    {"title": "m0 dies", "phase": "recovering",
     "pods": {"pod-0": {"m0": "dead"}},
     "calls": [{"to": "policy", "call": "Plan(...)", "out": "Unrecoverable"}]}
  ]
}
FieldValues
phasestarting, serving, recovering
member stateserving, paused, dead, excluded, starting, joining, unknown
Pod changemember states, a new uid, or "gone": true
calls[].toworkload, driver, policy, journal, telemetry
optionalpage (where the title links), note and journal on a step, in and out on a call
